Watch channels with VLC

1

Install VLC

Download VLC Media Player from the official VideoLAN website for Windows, macOS, Linux, Android or iOS.

Download VLC for Windows
2

Open a network stream

Open VLC and select Media → Open Network Stream. On macOS, use File → Open Network.

3

Paste the channel URL

Enter an official stream link or an .m3u/.m3u8 playlist URL, then click Play. VLC will connect directly to the broadcast.

Watching with a playlist: In VLC, select Media → Open File and choose a legally sourced .m3u file, or use Media → Open Network Stream for a playlist URL. Only use channels distributed with permission. Availability may vary by country and broadcaster.
