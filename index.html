Watch channels with VLC

1

Install VLC

Download VLC Media Player from the official VideoLAN website.

Download VLC for Windows
2

Open a network stream

Open VLC and select Media → Open Network Stream. On macOS, use File → Open Network.

3

Paste the channel URL

Enter an official stream link or an .m3u/.m3u8 playlist URL, then click Play.
